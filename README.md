# 🏠 House Price Prediction using Linear Regression

This project uses Machine Learning to predict house prices based on different property features such as area, bedrooms, bathrooms, parking, and other factors.

It is built using Python and Linear Regression to estimate accurate house prices.

---

## 🚀 Features
✔ Data Cleaning & Preprocessing  
✔ Exploratory Data Analysis (EDA)  
✔ Data Visualization  
✔ Linear Regression Model  
✔ Model Evaluation  
✔ Price Prediction  

---

## 🛠 Technologies Used
- Python
- Jupyter Notebook
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn

---

## 📊 Workflow
1. Import dataset  
2. Data preprocessing  
3. Visualization & analysis  
4. Train-test split  
5. Train Linear Regression model  
6. Evaluate performance  
7. Predict house prices  

---

## 📈 Model Output
The model predicts house prices based on input features and evaluates performance using:
- R² Score
- Mean Squared Error
- Residual analysis

---

## 🎯 Applications
- Real estate price estimation  
- Property investment planning  
- Market trend analysis  
- Business decision making
